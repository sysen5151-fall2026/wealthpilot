- N-01 已准备 10 组虚拟输入及实际计划输出；自动一致性检查 10/10 通过，但独立复核未完成，所以 N-01 继续跳过。

## 你现在可以完成 N-01 的真实独立复核

1. 请一位未编写该实现的同学担任独立复核人。不是让程序代填。
2. 双击 `evidence/acceptance/N01_独立复核表.html`，浏览器打开即可。
3. 每组比较虚拟输入与实际输出中的目标、期限、资金能力和持仓，填写真实判断及理由。十组都要复核，至少九组通过。
4. 填复核人编号、实际日期和独立性确认；点击“导出真实复核记录”。关闭表格前先导出，未导出的内容不会保存。
5. 把下载的 `n01-independent-review-packet.json` 放回项目的 `evidence/acceptance/`，替换同名文件。建议先保留原件备份。
6. 运行 `.venv/bin/python -m pytest tests/test_spec_acceptance.py -k N01 -v -rs`。有完整真实记录、9/10 通过、且计划基线未变化，测试才会通过；无记录仍跳过，错误记录会失败。

记录验证只能检查完整性、数量和基线匹配，不能保证填写者诚实；保留真实复核笔记。自动检查通过不表示投资建议正确或规则已获团队批准。
